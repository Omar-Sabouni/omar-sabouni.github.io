The project replays built-in conveyor scenes rather than consuming a live camera feed.

Local workflow

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py

FastAPI serves completed-run data and annotated JPEG frames; the browser replays them with HTML transport controls and a Canvas defect chart.
