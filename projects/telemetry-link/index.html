TelemetryLink

A dependency-free C++20 library and command-line decoder for heartbeat, IMU, and motor-status frames arriving in arbitrary chunks.

Runtime dependencies
None
Parser edge cases
30
Synthetic benchmark
2 million frames

JSON Lines is the interface

{"kind":"message","version":1,"sequence":0,"sequence_status":"first","type":"heartbeat","payload":{"uptime_ms":1000,"status_flags":0}}
{"kind":"message","version":1,"sequence":3,"sequence_status":"gap","expected_sequence":2,"missing_before":1,"type":"heartbeat","payload":{"uptime_ms":1750,"status_flags":3}}
...
{"kind":"health","status":"degraded","bytes_received":498,"frames_decoded":13,"heartbeat_frames":5,"imu_sample_frames":4,"motor_status_frames":4,"noise_bytes":105,"invalid_versions":0,"unknown_types":0,"invalid_lengths":1,"crc_failures":2,"payload_failures":0,"truncated_frames":0,"truncated_bytes":0,"sequence_gaps":5,"missing_frames":5,"out_of_order_frames":0}

The parser scans past line noise, invalid lengths, garbage, and CRC failures while preserving valid frames that follow. EOF adds one health record; optional human diagnostics remain on stderr when --diagnostics is enabled.

Build, decode, render

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
python3 tools/simulate.py --scenario mixed --count 18 --output mixed.bin
./build/telemetry-link --diagnostics mixed.bin > mixed.jsonl
python3 tools/render_report.py mixed.jsonl --output report.html
