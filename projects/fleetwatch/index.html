FleetWatch

A local FastAPI and SQLite console for robot telemetry, health, signal freshness, incidents, and shift controls.

ConditionDerived fromOperator state

Event ingestion is idempotent. Health and freshness are derived from event time, while incident acknowledgement is an explicit operator action.
