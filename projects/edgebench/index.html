InferQual

Source code

InferQual times PyTorch and ONNX Runtime and picks the fastest backend whose output matches PyTorch.

$ inferqual run --device cpu
Runtimep50p95Samples/sCosine similarity
ONNX Runtime INT80.69 ms0.83 ms1,4490.99999
ONNX Runtime FP320.77 ms0.80 ms1,3041.0
PyTorch FP321.28 ms1.50 ms7791.0

These times depend on the machine.
